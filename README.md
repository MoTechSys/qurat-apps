## 🔒 القفل والفتح عن بُعد: `qurat-almahalat/license.json`

عدّله من واجهة GitHub (أيقونة القلم ✏️ ثم **Commit changes**)، أو بالأداة `tools/qurat_control.py` في المستودع الخاص.

```json
{
  "active": true,
  "codeSha256": "…",
  "message": "النص الذي يظهر للمستخدم عند القفل",
  "blockedDevices": [],
  "blockedMessage": "رسالة الأجهزة المحظورة",
  "offlineGraceDays": 0,
  "contact": "+967770941666"
}
```

| ماذا تفعل | النتيجة في التطبيق |
|---|---|
| `"active": false` | 🔒 يُقفل عند الجميع ويطلب **كود التفعيل** (تظهر `message`) |
| `"active": true` | ✅ يفتح فورًا عند الجميع |
| تغيير `codeSha256` | يُقفل كل من فعّل بالكود القديم (ما دام `active: false`) |
| إضافة معرّف جهاز إلى `blockedDevices` مثل `["3F2A-91BC"]` | قفل **هذا الجهاز فقط** حتى لو `active: true`، والكود لا يفتحه |
| `"offlineGraceDays": 7` | يُقفل الجهاز إن مرّ 7 أيام دون أي تحقق ناجح (يمنع التحايل بقطع الإنترنت). `0` = معطّل |
| **حذف الملف** | ⛔ قفل نهائي بلا كود لكل نسخة سبق أن قرأته |
| ملف تالف أو بلا إنترنت | آخر حالة معروفة، ولا يحدث قفل خاطئ أبدًا |

- **متى يلتقط التطبيق التغيير؟** عند فتحه، وعند الرجوع إليه (كل 10 دقائق كحد أدنى). المصدر الأساسي GitHub API (بلا كاش)، والاحتياطي raw (قد يتأخر حتى 5 دقائق).
- **معرّف الجهاز** يظهر للمستخدم في شاشة القفل وفي «عن التطبيق» (مثل `3F2A-91BC`)، ويرسله لك بزر واتساب.
- **الكود لا يُكتب نصًّا** هنا لأن المستودع عام. يُخزَّن كبصمة `codeSha256` (SHA-256 للكود بأحرف كبيرة بلا مسافات). لتوليد البصمة:
  ```bash
  python3 tools/qurat_control.py set-code QRT-XXXX-XXXX     # يكتبها في الملف مباشرة
  # أو يدويًا:
  echo -n "QRT-XXXX-XXXX" | sha256sum
  ```
- البيانات (المسابقات والمشاركون) **لا تُمس أبدًا**؛ القفل يحجب الواجهة فقط.

## 🔄 التحديث عن بُعد: `qurat-almahalat/update.json`

يكتبه تلقائيًا `tools/publish_release.py` بعد نشر الإصدار والتحقق من الملفات المنشورة.

```json
{
  "version": "1.2.0", "build": 120,
  "versionCodes": { "arm64": 2120, "armv7": 1120, "x86_64": 4120 },
  "apks": { "arm64": { "url": "…", "sha256": "…", "size": 0 }, "…": {} },
  "notes": "ما الجديد", "publishedAt": "2026-10-30",
  "minSupportedBuild": 0
}
```

- التطبيق يختار ملف **معمارية النسخة المثبّتة**، ثم يُنزّله ويرفض أي ملف لا يطابق `sha256` أو `size`، ثم يفتح مثبّت النظام.
- يُفحص تلقائيًا كل 6 ساعات، وزر «لاحقًا» لا يكرر التنبيه لنفس الإصدار.
- `minSupportedBuild`: أي نسخة رقم بنائها أقل منه تُجبر على التحديث (شاشة تحجب التطبيق). **للإصلاحات الحرجة فقط.**
- حذف الملف أو إبقاؤه قديمًا = لا يظهر تحديث (آمن).
